# homebrew-tap

Homebrew formulas for the [missionctl](https://github.com/aeon022/missionctl) suite.

```bash
brew tap aeon022/tap
brew install aeon022/tap/taskctl     # or mailctl, calctl, notectl, budgetctl, habctl, timectl, diaryctl
```

Formulas in `Formula/` are updated automatically by each tool's goreleaser release workflow.
